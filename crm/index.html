CRM de Pacientes – IMO

Para começar, escolha o arquivo de pacientes que está no seu computador (por exemplo CRM-Pacientes-IMO-v2.html, na pasta Downloads).

Os dados são lidos direto do seu computador e ficam guardados só neste navegador. Nada é enviado para a internet nem para o GitHub.

Mensagens prontas

Edite à vontade: tudo fica salvo automaticamente neste navegador. Use {nome} para o primeiro nome do paciente, {ultima} para a data da última consulta e {consultas} para o número de consultas. Para negrito no WhatsApp, coloque o texto entre asteriscos: *assim*.
